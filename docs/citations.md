# Citations & References

### 1. Primary Dataset
- **Title**: Customer Support on Twitter Dataset
- **Source**: Kaggle (`thoughtvector/customer-support-on-twitter`) / Hugging Face (`SunidhiSriram/twcs`)
- **Author**: Thought Vector (Kaggle)
- **URL**: https://www.kaggle.com/datasets/thoughtvector/customer-support-on-twitter
- **Description**: Public collection of 2.81 million customer support tweets and multi-turn brand replies on Twitter.

---

### 2. Secondary Dataset (Optional Benchmark Reference)
- **Title**: Banking77 Dataset
- **Source**: Hugging Face (`PolyAI/banking77`)
- **Author**: PolyAI (Casanueva et al., 2020)
- **URL**: https://huggingface.co/datasets/PolyAI/banking77
- **Description**: Single-domain intent dataset with 13,083 queries and 77 fine-grained intents. Evaluated during intent taxonomy design; custom 10-intent taxonomy was chosen instead to reflect consumer tech / Apple support issues.

---
